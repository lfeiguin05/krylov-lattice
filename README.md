# Lattice - Lanczos 

A Python implementation of **Lanczos** and **Block Lanczos** algorithms to describe the states of electrons within a substrate in different bases following the method of Allerdt & Feiguin *A Numerically Exact Approach to Quantum Impurity Problems in Realistic Lattice Geometries* :contentReference[oaicite:0]{index=0}.
This repository generates the following:
- Adjacency-based Hamiltonian mapped to 2D coordinate system off of one (lanczos) or multiple (block lanczos) seeds
- Applies block lanczos for multi seed (impurity) systems
- Built-in visualization of lanczos residuals W, and mapped lattice amplitudes
