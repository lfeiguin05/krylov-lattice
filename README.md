# Lattice - Lanczos 

A Python implementation of **Lanczos** and **Block Lanczos** algorithms to describe the states of electrons within a substrate in different bases. 
This repository generates the following:
- Adjacency-based Hamiltonian mapped to 2D coordinate system off of one (lanczos) or multiple (block lanczos) seeds
- Constructs tridiagonal matrices from  \(T\) from \(\{A_n, B_n\}\)
